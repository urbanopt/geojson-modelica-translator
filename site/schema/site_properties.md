# URBANopt Site

*Schema for an URBANopt Site object*

## Properties

- <a id="properties/id"></a>**`id`** *(string)*: Unique id used to refer to this feature within this dataset, generated by database.
- <a id="properties/project_id"></a>**`project_id`** *(string)*: Project which this feature belongs to.
- <a id="properties/name"></a>**`name`** *(string)*: Feature name.
- <a id="properties/state"></a>**`state`** *(string)*: State name.
- <a id="properties/city"></a>**`city`** *(string)*: City name.
- <a id="properties/latitude"></a>**`latitude`** *(number, required)*: Latitude of site origin in WGS 84 coordinate system (deg).
- <a id="properties/longitude"></a>**`longitude`** *(number, required)*: Longitude of site origin in WGS 84 coordinate system (deg).
- <a id="properties/surface_elevation"></a>**`surface_elevation`** *(number)*: The surface elevation (above NAVD88 datum) of the project (ft).  .
- <a id="properties/import_surrounding_buildings_as_shading"></a>**`import_surrounding_buildings_as_shading`** *(boolean)*: If true, import geometry from surrounding buildings when performing energy calculations.
- <a id="properties/timesteps_per_hour"></a>**`timesteps_per_hour`** *(integer)*: Number of timesteps per hour for energy simulations. Minimum: `1`. Maximum: `60`.
- <a id="properties/begin_date"></a>**`begin_date`** *(string)*: Date to begin simulation, format YYYY-MM-DD.
- <a id="properties/end_date"></a>**`end_date`** *(string)*: Date to end simulation, format YYYY-MM-DD.
- <a id="properties/climate_zone"></a>**`climate_zone`** *(string)*: ASHRAE 169 climate zone.
- <a id="properties/cec_climate_zone"></a>**`cec_climate_zone`** *(string)*: CEC Title24 climate zone.
- <a id="properties/default_template"></a>**`default_template`** *(string)*: Default OpenStudio Standards template.
- <a id="properties/weather_filename"></a>**`weather_filename`** *(string)*: Name of weather file in EPW format.
- <a id="properties/tariff_filename"></a>**`tariff_filename`** *(string)*: Name of utility tariff file in IDF or URDB format.
- <a id="properties/user_data"></a>**`user_data`**: Arbitrary user data.
